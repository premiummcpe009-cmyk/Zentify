# Zentify

Minimal, glassmorphism YouTube / YouTube Music client for Android.
Search + streaming via [InnerTubeX](https://github.com/MetrolistGroup/innertubex).

- Jetpack Compose UI, blurred artwork background, frosted glass panels
- Media3 background playback with notification controls
- Music (YouTube Music) and Video (YouTube) modes
- All InnerTubeX calls live in `app/src/main/java/com/zennyx/zentify/data/YtEngine.kt`

Build: run the **Build Zentify APK** workflow, then install the APK from the Releases tab.
